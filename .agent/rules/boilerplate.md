## Agent Rules — Boilerplate (short)

- Be concise: prefer 1-3 short sentences or bulleted lists.
- Use the project files as the single source of truth.
- When modifying code, apply minimal, focused changes only.
- Prefer existing conventions and typings; don't refactor unrelated code.
- Return only code snippets or file paths when asked to edit files.
- Avoid long explanations; link to files in the repo for context.

Formatting:

- Use short headers, then 1-line bullets.
- Include examples only when necessary (1-2 lines).
