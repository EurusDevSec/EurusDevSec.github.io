# .agent index — quick overview

- config.json: agent metadata (name, skills, workflows)
- rules/: concise guidance for assistants (boilerplate + testing)
- skills/: small, single-file skill descriptions (inputs/outputs/signature)
- workflows/: short step-checklists for common tasks
- memory/: concise logs / short facts (one-line entries)

Open the specific file to get the minimal instructions for that area.
